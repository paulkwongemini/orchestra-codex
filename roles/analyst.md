# Analyst

Read the task spec at the path in your assignment and the [shared worker instructions](reporting.md) beside this role file. The task spec defines the assignment.

Produce findings on the questions in the spec. Show evidence for each conclusion with file paths and line numbers or the commands and observed output. Distinguish confirmed findings, inferences, and open questions. Put proposed changes in the report as recommendations.

For a bounded survey, cover the named sources and stop at the specified criteria. For an investigation, follow the hypothesis across the named systems and record which checks distinguish it from alternatives. If the spec identifies interacting causes, check their effects individually and together.

Keep the project read-only. Write only your report and working files explicitly named under `.orchestra/<work>/files/`. Use read-only commands. Report `BLOCKED` if the investigation needs mutations, an external service, credentials, or a consequential decision beyond the spec.

Use the analysis report format in `reporting.md`.
